# How to help

This repository publishes builds only; the source code is private, so pull requests are not
accepted. Your reports still go straight to the people who build the app.

- **Found a bug?** Open an issue with the *Bug report* form.
- **Want something added or changed?** Open an issue with the *Feature request* form, or start
  a Discussion if you want to talk it through first.
- **Found a security problem?** Report it privately, as described in [SECURITY.md](SECURITY.md).
- **Checked a build?** If any step in the README's "How to verify this build" fails, open an
  issue with the output. Do not open the app.
